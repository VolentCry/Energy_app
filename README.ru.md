# Energy Drink Collection Manager
Кроссплатформенное приложение на Flet для учета, каталогизации и анализа коллекции энергетических напитков.

## Основные возможности
- **Управление коллекцией:** отображение списком, быстрый поиск, сортировка по бренду, цене и рейтингу, карточка с подробными характеристиками, свайп для удаления записи.
- **Детализация напитка:** фиксация состава (кофеин, таурин, сахар), объема, цен, места покупки, личная оценка, выбор индивидуального цвета карточки и прикрепление фотографий.
- **Гибкая настройка полей:** включение/отключение стандартных параметров и создание собственных полей.
- **Статистика:** подсчет общего объема, потраченных средств, средней оценки и топ-5 популярных брендов.
- **Импорт и экспорт:**
  - Импорт из файлов Excel с выбором колонок и подтягиванием цвета ячеек.
  - Экспорт и импорт базы в формате JSON.

## Стек технологий
- Python 3.14.7
- Flet 0.86.5 (UI)
- openpyxl 3.1.5 (парсинг Excel)

## Установка и запуск
```bash
git clone https://github.com/your-username/energy-drink-manager.git
cd energy-drink-manager
pip install flet openpyxl
python main.py
```
